## Why this matters now
AI tooling has moved from pilots to production usage. Students and faculty increasingly expect AI-supported discovery, recommendation, and synthesis features in library workflows.

## Priority risks
- **Attribution gaps and hallucination**
- **Bias amplification in ranking and summarization**
- **Privacy leakage from query and context collection**

## Responsible deployment pattern
1. Start with a narrow workflow and explicit user outcomes.
2. Require provenance and confidence transparency for every generated response.
3. Maintain human review and complaint pathways from day one.

## Action checklist
- Define service-level criteria for accuracy and privacy before launch.
- Add model behavior disclosures in interface copy.
- Log and review user feedback weekly during pilots.
