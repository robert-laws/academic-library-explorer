## Why this matters now
Digital output types are expanding beyond journal articles. Libraries now steward text, data, software, and media with different risks and retention lifecycles.

## Core risks
- Undefined retention and migration policy by format
- Weak integrity checks and recovery tests
- Insufficient staffing for long-term migration workflows

## Strategic response
- Standardize preservation categories by format and risk.
- Publish fixity and fixity-check metrics as routine deliverables.
- Run periodic restore and migration simulations.

## Action checklist
- Add annual format migration plans to repository governance.
- Require fixity checks at ingest and quarterly review.
- Define responsibility ownership for preservation incidents.
