## Why this matters now
Discovery systems are only as effective as the metadata they can trust. Inconsistent identifiers and weak authority control reduce discoverability for both people and programs.

## Symptom patterns
- Duplicate records and mismatched authority terms
- Gaps between article, dataset, and repository references
- Legacy catalog fields blocking modern faceted search

## Practical response
- Standardize contributor workflows with shared vocabularies.
- Automate validation checks at ingestion points.
- Add a clear metadata correction path with response time targets.

## Action checklist
- Review identifier hygiene for high-use collections.
- Add validation gates to every new ingest batch.
- Publish a shared metadata error taxonomy for staff and partners.
