## Why this matters now
Subscription inflation and exchange-rate shifts are weakening planning confidence. User expectations for continuous access continue to rise at the same time.

## Strategic levers
- Use consortial structures for leverage and shared market intelligence.
- Separate core subscriptions from optional strategic services.
- Tie renewals to usage, outcomes, and practical alternatives.

## Recommended operating model
1. Build a public renewal calendar with decision checkpoints.
2. Track cancellation impact using collection and teaching evidence.
3. Run leadership reviews against measurable value, not only price.

## Action checklist
- Publish renewal and contract milestones for each license.
- Define minimum access requirements and fallback plans.
- Require a value and impact note for all renewal extensions.
