# Contributing

Thank you for improving the portal.

## Editorial scope

- Prioritize practical, policy-aware content for academic librarians.
- Keep recommendations actionable and evidence-linked.
- Use a neutral, professional tone.

## Adding a topic

1. Create `content/topics/<slug>.md`.
2. Include all required front matter fields.
3. Add at least two external references.
4. Run build check:
   - `node scripts/build.js --strict`

## Adding an issue brief

1. Create `content/briefs/<slug>.md`.
2. Include all required front matter fields.
3. Keep the brief concise and implementation-oriented.
4. Run build check.

## Code review checklist

- Factual clarity
- Source quality
- Accessibility and readability
- Reference formatting
- No broken links
